# 渡口 · 模型网关

单节点 Go 网关和 React 管理控制台，共用 SQLite 保存模型、网关密钥配置、调用账务与媒体任务。当前工作区的试用地址为 [本地控制台](http://127.0.0.1:8787)。测试账号和密码均为 `admin`。

## 启动

在项目根目录运行。已在本机完成构建的工作区可直接执行 `./model-gate`。从源码构建需要 Go 1.26 或以上，以及支持 Vite 5 的 Node.js 与 npm。

```sh
npm ci --prefix web
npm run build --prefix web
go build -trimpath -o model-gate .
./model-gate
```

默认监听本机回环地址。服务端自动读取私有配置。进程退出后，使用同一个数据库路径重新启动即可恢复业务记录和已提交的厂商任务。[环境说明](环境说明.md)

## 试用

1. 在「渠道与模型」手动设置上游模型 ID 和网关别名，也可以从厂商获取列表并勾选导入。获取列表仅查询厂商，确认导入才写入配置。星标保存在工作区数据库。不同渠道需要同名上游模型时可分别设置别名。
2. 在「网关密钥」创建 Key，指定模型权限、总额度、每分钟请求数和并发数。创建时显示一次完整密钥。已有 Key 可在 Playground 直接选用。API 客户端使用 `Authorization: Bearer <网关密钥>`。
3. 在 Playground 选择模型，填写系统提示和消息，可调整温度、输出上限，进行流式多轮对话。停止会取消浏览器读取并向上游传递取消信号。重新发送需确认可能产生新费用。切换模型保留上下文，切换 Key 清空会话。导出的 Markdown 按时间顺序保留用户与助手消息。
4. 视频生成可选 MiniMax 或 Seedance。只填画面描述即可文生视频，上传 PNG 或 JPEG 首帧即可图生视频。完成后在任务记录中预览或下载。声音工作室提供普通朗读、流式朗读、长文本配音、音乐、音色复刻和音色设计。
5. 在「调用日志」粘贴完整请求 ID 查询。Playground 回执可直接跳转。明细 CSV 包含所选范围的全部记录。用量页按浏览器本地日期筛选，结束日期含当天，费用合计与模型分组独立于分页。
6. 顶栏可选浅色、深色或跟随系统。主题偏好保存在浏览器。Playground 手输的密钥仅保存在页面内存。

### API 示例

先在调用进程设置环境变量 `GATEWAY_KEY`。请求 ID 位于响应头 `X-Request-ID`。

```sh
curl -sS http://127.0.0.1:8787/v1/models \
  -H "Authorization: Bearer $GATEWAY_KEY"

curl -sS -N http://127.0.0.1:8787/v1/chat/completions \
  -H "Authorization: Bearer $GATEWAY_KEY" -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-v4-flash","messages":[{"role":"user","content":"你好"}],"max_tokens":64,"stream":true}'

curl -sS http://127.0.0.1:8787/v1/embeddings \
  -H "Authorization: Bearer $GATEWAY_KEY" -H 'Content-Type: application/json' \
  -d '{"model":"embedding-3","input":["第一段文本","第二段文本"]}'
```

聊天接受文本消息，向量接受单条文本或最多 128 条的文本列表。当前文本体验使用 DeepSeek 非思考模式。已登记的旧别名 `deepseek-v4-flash` 仍可调用。新建配置也可使用模型列表返回的 `deepseek-flash`。

## 额度与账务

- **配置费率**。模型编辑框的单价单位为元 / 百万 Token。有限额度需要厂商确实强制执行的单条输入 Token 上界、适用费率和聊天输出上限。填入的费率应覆盖当前模型、时段和缓存策略。上游采用阶梯价格或不同账户折扣、无法确认适用费率时，请保留未知配置。有限 Key 会在转发前收到明确拒绝。无限 Key 可继续调用并登记待核实账。
- **预留**。每次转发前，在同一笔短事务内检查模型权限、最近 60 秒请求数、在途数、已结算金额及已有占用。预留等于输入硬上界 × 输入条数 × 最高输入单价，加上请求最大输出 Token × 输出单价。聊天将最大输出显式传给上游。所有金额使用十亿分之一元的整数单位。网络 I/O 在事务外并行执行。
- **结算**。已确认费率乘以厂商返回的实际输入、缓存命中和输出 Token 结算。未发送的失败记零。取消、断流、超时和错误响应中可核验的用量仍可结算。缺失用量或费率则保留待核实状态及原预留。有公开目录价的记录可显示独立费用估算。估算与未知费用均不进入已结算合计。
- **恢复**。请求 ID 唯一。一次调用固定渠道，网关不对生成请求自动换渠道或重发。管理员配置变更作用于后续请求。异常退出后程序保留在途预留并将记录移入待核实。管理员在调用详情填写厂商账单金额和依据即可完成一次结算并释放占用。已处理记录拒绝重复结算。无限额期间产生的无上界待核实记录，在切换为有限额后需先核实。
- **媒体**。媒体任务以 `job_` 开头的 ID 进入账务日志，归于控制台账户。聊天和向量的 Key 额度仅适用于对应网关接口。公开媒体价可用于估算，只有核实的费用进入合计。创建专属音色并试听后，首次正式使用还可能触发厂商的一次性音色费用。

## 长文本、音乐与音色

长文本使用 MiniMax 原生异步任务，提交后保留厂商任务 ID，重启后继续轮询。厂商返回处理阶段时，页面显示该阶段。任务完成后，服务端保存成品包。网页刷新、下载和重复试听已有成品均无需重新生成。

当前提供的 MiniMax 账号调用托管音乐返回 HTTP 410。支持已有有效音乐权限的账号，也可在服务端设置 `MUSIC3_BASE_URL`，指向自托管 MiniMax Music 3 服务，例如 `http://127.0.0.1:8000`。重启后，音乐页将歌词和风格发往该服务的 `/v1/audio/speech` 并保存 WAV，厂商密钥仅用于各自的官方渠道。部署自托管模型需要另备适配的 GPU 环境。[官方音乐服务说明](https://platform.minimaxi.com/docs/api-reference/music-generation.md) · [官方自托管指南](https://platform.minimaxi.com/docs/guides/local-deploy-music-3.md)

复刻与设计完成后可试听，在任务卡上选择「使用此音色朗读」并填写新文案。上传样音需确认授权。流式朗读按 24 kHz PCM 音频分块播放，可随时停止；普通朗读提供 MP3 下载。

## 检查与升级

```sh
go test -race ./...
go vet ./...
npm run build --prefix web
```

升级前停止服务并备份整个数据库目录及其成品目录。替换程序和前端后，沿用原 `SQLITE_PATH` 启动。程序按版本在事务中执行迁移，并用文件锁保护单实例启动。数据库版本高于当前程序时会拒绝启动。原工作区为空，本仓库可从空库启动，也覆盖本项目第一个 schema 到当前版本的升级。其他网关产品的数据迁移需要单独映射。
